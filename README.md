# 프렌즈 설치하기

## 1. 내려받기

**[최신 버전 내려받기](https://github.com/wndPwls/friends-releases/releases/latest)** 페이지에서 `Friends-Setup-버전.exe`를 눌러 받아요.

## 2. 설치하기

받은 파일을 실행하면 바로 설치되고 프렌즈가 켜져요. 바탕화면에 바로가기도 생겨요.

처음 실행할 때 파란 **"Windows의 PC 보호"** 창이 뜰 수 있어요. 작은 팀이 만든 앱이라 Microsoft 인증서가 없어서 그래요.
**추가 정보**를 누른 뒤 **실행**을 누르면 돼요.

## 3. 시작하기

관리자에게 받은 초대 코드(`FRND-숫자4자리-영문4자리`)를 영어 입력 상태에서 넣으면 시작돼요.

## 업데이트

새 버전이 나오면 프렌즈가 알아서 받아요. 다 받으면 다시 시작할지 물어보고, "나중에"를 눌러도 프렌즈를 끌 때 적용돼요.
