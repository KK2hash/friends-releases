# 프렌즈 설치하기

## 1. 내려받기

**[최신 버전 내려받기](https://github.com/wndPwls/friends-releases/releases/latest)** 페이지에서 `Friends-Setup-버전.exe`를 다운 받습니다.

## 2. 설치하기

받은 파일을 실행하면 바로 설치되고 프렌즈가 켜집니다.

처음 실행할 때 파란 **"Windows의 PC 보호"** 창이 뜰 수 있는데, **추가 정보**를 누른 뒤 **실행**을 누르면 됩니다.

## 3. 시작하기

관리자에게 받은 초대 코드(`FRND-숫자4자리-영문4자리`)를 기입해야 앱이 실행됩니다.

## 업데이트

새 버전을 자동으로 업데이트합니다. 다 받으면 다시 시작할지 물어보고, "나중에"를 누르면 앱을 끈 상태일 때 다운 받습니다.
