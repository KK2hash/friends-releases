# 프렌즈 설치하기

## 1. 내려받기

**[최신 버전 내려받기](https://github.com/wndPwls/friends-releases/releases/latest)** 페이지에서 `Friends-Setup-버전.exe`를 다운 받습니다.

## 2. 설치하기

받은 파일을 실행하면 바로 설치되고 프렌즈가 켜집니다.

처음 실행할 때 파란 **"Windows의 PC 보호"** 창이 뜰 수 있는데, **추가 정보**를 누른 뒤 **실행**을 누르면 됩니다.

## 3. 시작하기

관리자에게 받은 초대 코드(`FRND-숫자4자리-영문4자리`)를 기입해야 앱이 실행됩니다.

## 업데이트

새 버전을 자동으로 업데이트합니다. 다 받으면 다시 시작할지 물어보고, "나중에"를 누르면 앱을 끈 상태일 때 다운 받습니다.


## 앱 기능 설명

좌측 메뉴 7개: 홈, 친구, 채팅, 캐릭터, 같이 놀기, 내 정보, 문의사항

  • 홈 탭에서 내 프로필을 꾸밀 수 있습니다. 총 작업량은 앱을 켜둔 시간을 기록합니다.

  • 친구 탭에서 닉네임으로 친구를 찾고 친구 추가를 할 수 있습니다. 친구의 홈 방문이 가능합니다.

  • 채팅 탭에서 친구와 1:1 채팅이 가능합니다.
  
  • 캐릭터	탭에서 직접 얼굴을 그리거나 파일을 불러와 캐릭터를 생성합니다. 옷장 기능 또한 캐릭터 탭에 있습니다.
    캐릭터는 얼굴과 앞머리까지만 그릴 수 있어서 머리 나머지 부분은 후드나 모자로 가리는 걸 추천합니다. 안 그러면 탈모가 됩니다.
  
  • 같이 놀기 탭에서 방을 만들거나 코드로 들어가 화면에 친구와 내 캐릭터를 함께 띄울 수 있습니다.
    같이 놀기 탭 내에 있는 채팅을 입력하면 캐릭터 머리 위에 말풍선이 생깁니다.
    실수로 앱을 꺼도 방에서 나가지지 않습니다.
    얼굴 수정, 옷 변경이 실시간으로 적용됩니다. 시간이 소요될 수 있습니다.
    
  • 내 정보 탭에서	색상, 크기, 캐릭터 설정 등을 수정할 수 있습니다.
  
  • 문의사항	탭은 관리진만 볼 수 있는 비공개 글을 게시합니다. 문의를 게시하면 관리자가 확인 후 답장합니다.


## 캐릭터 기능

캐릭터는 작업 표시줄 위를 돌아다니며, 가만히 두면 혼자 움직입니다.

  • 마우스를 가까이 가져가면 시선이 마우스를 따라갑니다.
  
  • 클릭하면 뛰어오릅니다. 자고 있을 때 클릭으로 깨울 수 있습니다.

  • 빠르게 세 번 클릭하면 두 손으로 머리를 가립니다. 
    이 상태로 계속 클릭하면 짜증을 냅니다.
    
  • 잡아서 끌면 버둥거립니다. 
  
  • 잡고 좌우로 세게 흔들었다가	내려놓으면 어지러워합니다.

  • 우클릭 1번	그 자리에 앉습니다.
    우클릭 2번	책상 앞에 앉아 노트북을 두드립니다.
    우클릭 3번	다시 일어나 돌아다닙니다.

  • 앉혀 두면 다시 우클릭할 때까지 걷거나 졸지 않습니다.
  
  • 보는 방향은 끌고 간 쪽입니다. 왼쪽으로 가져가서 내려놓으면 왼쪽을 보고, 그 상태에서 앉히면 왼쪽을 보고 앉습니다.
  
  • 컴퓨터 앞에 앉아 있을 때는 클릭해도 반응하지 않고 빡집중합니다. 잡아서 옮길 수는 있습니다.
  
  • 캐릭터 크기, 숨기기, 위치 고정, 어느 모니터에 둘지는 내 정보에서 바꿀 수 있습니다.


## 캐릭터 꾸미기

캐릭터 메뉴 기능. 바꾼 것은 저장 단추 없이 바로 바탕화면 캐릭터에 반영됩니다.

도구 / 단축키 /설명

펜 / B	/ 색을 골라 그림 / 태블릿 필압을 지원
지우개	/ E	/ 지금 레이어의 그림을 지움
스포이트 / I / 또는 Alt+클릭	/ 그림에서 색을 뽑음
굵기 조절	/ [ ]	슬라이더로도 바뀜
되돌리기	/ Ctrl+Z	
다시 하기	/ Ctrl+Y	

투명도: 펜의 진하기
대칭자: 켜면 가운데 선을 기준으로 좌우가 같이 그려짐
손떨림 방지: 선이 매끄럽게 됨
레이어: 총 2장
휴지통: 현재 레이어 전체 삭제

    ! 얼굴 칸의 점선 안쪽이 후드나 모자를 써도 가려지지 않는 범위입니다. 눈 사이를 넓게 그리면 귀엽게 나옵니다.


PNG 저장: 지금 보이는 얼굴 그림을 PNG 파일로 내 컴퓨터에 저장.
불러오기: PNG 파일을 지금 고른 레이어로 불러옴. 레이어에 있던 그림은 지워지지만 Ctrl+Z로 되돌릴 수 있음.


## QnA

Q. 프렌즈를 지웠다가 다시 깔아도 내 계정이 그대로인가요? 
A. 같은 컴퓨터라면 그대로예요. 다시 깔고 켜면 초대 코드를 묻지 않고 바로 들어와요.

Q. 컴퓨터를 바꾸면 어떻게 되나요? 
A. 계정은 컴퓨터에 묶여 있어서 다른 컴퓨터로 옮길 수 없어요. Windows를 다시 설치한 경우도 같아요. 관리자에게 새 초대 코드를 받아 새 계정으로 시작해야 해요. 얼굴 그림은 미리 PNG로 저장해 두면 새 계정에서 불러올 수 있어요.

Q. 캐릭터가 안 보여요.
A. 내 정보의 캐릭터 꺼내기가 체크되어 있는지 봐 주세요. 모니터가 여러 대라면 내 정보의 캐릭터가 있을 모니터를 확인해 주세요. 그래도 안 보이면 앱을 껐다 켜 주세요.

Q. 캐릭터나 앱이 클릭되지 않아요. 
A. 트레이의 프렌즈 아이콘을 우클릭해서 종료한 다음 다시 켜 주세요. 계속 반복되면 문의사항으로 알려 주세요.

Q. 같이 놀기에서 친구 캐릭터가 안 보여요.
A. 두 사람이 같은 방 코드에 들어와 있는지 방 화면의 사람 목록에서 확인해 주세요. 
두 사람 모두 최신 버전인지 확인해 주세요. 구 버전일 경우 프렌즈를 껐다 켜면 새 버전을 다운 받을 수 있습니다.
내 정보의 캐릭터 꺼내기가 풀려 있으면 방 사람들의 캐릭터도 안 보여요.
